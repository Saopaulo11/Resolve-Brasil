# Бренд-ассеты — ПЛЕЙСХОЛДЕР

Эти файлы **не являются утверждённым логотипом**.

Спецификация (§72) ссылается на «утверждённую концепцию №7», но самого файла
в задании не было. Выдавать нарисованное здесь за утверждённый бренд нельзя,
поэтому знак собран строго по текстовому описанию:

- круговой символ из зелёного, жёлтого и синего элементов;
- `Resolve` — deep navy (`#10243E`), `Brasil` — green (`#00803F`).

## Что заменить, когда придёт настоящий файл

| Файл | Где используется |
| --- | --- |
| `logo-horizontal.svg` | шапка сайта, подпись писем |
| `logo-vertical.svg` | заставки, печатные материалы |
| `icon.svg` | favicon, иконка PWA |
| `logo-mono-light.svg` | монохром на светлом фоне |
| `logo-mono-dark.svg` | монохром на тёмном фоне |

Имена файлов — часть контракта: замените содержимое, не трогая пути, и
интерфейс подхватит новый знак без правок кода.

## Растровые файлы

Выведены из `icon.svg` — то есть из того же плейсхолдера, и утверждённым
знаком не являются ровно в той же мере.

Раньше их здесь не было намеренно: экспортировать растр из плейсхолдера
казалось неправильным. Цена оказалась выше пользы — Android без растровых
иконок не предлагает установку и ставит иконку по умолчанию, iOS не берёт
SVG в `apple-touch-icon`, а ссылка без картинки приходит в WhatsApp пустым
прямоугольником. SVG-плейсхолдер и так стоит на сайте фавиконом, так что
растр из него ничего не меняет в вопросе утверждения знака.

| Файл | Размер | Для чего |
| --- | --- | --- |
| `../../icons/icon-192.png` | 192×192 | установка PWA |
| `../../icons/icon-512.png` | 512×512 | установка PWA, заставка |
| `../../icons/icon-maskable-512.png` | 512×512 | Android, `purpose: maskable` |
| `../../icons/apple-touch-icon.png` | 180×180 | иконка на экране iOS |
| `og-card.png` | 1200×630 | превью ссылки (WhatsApp, соцсети) |

Когда придёт утверждённый исходник, эти файлы нужно перевыпустить из него —
не пересохранять нынешние. Требования: прозрачный фон у `icon-192` и
`icon-512`; у `maskable` фон во всю площадь, а знак в центральных 60%
(остальное срезается под маску устройства); у `apple-touch-icon` фон
сплошной — iOS не умеет прозрачность и подставит чёрный.

Проверка следит за тем, что каждая иконка из манифеста отдаётся и что
растровые размеры на месте: манифест со ссылкой на несуществующий файл
выглядит исправным, но установку ломает молча.
